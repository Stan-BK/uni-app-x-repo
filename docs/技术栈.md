# 技术栈说明

> 本文档是本项目的技术选型与工程约束基线。后续开发（含 AI 辅助）应以本文为准；若需变更，先改本文与相关 ADR，再改代码。

**文档版本：** 2026-10-17  
**适用阶段：** monorepo 基座 / 全栈 MVP  
**关联 ADR：** [0001](./adr/0001-monorepo-and-tech-stack.md)、[0002](./adr/0002-doc-driven-ai-workflow.md)

---

## 1. 结论（先读）

| 决策项 | 选择 |
| --- | --- |
| 仓库形态 | **pnpm monorepo** |
| 小程序框架 | **传统 uni-app（Vue3）**，不使用 uni-app x |
| 小程序构建 | **Vite** |
| 小程序状态 | **Pinia** |
| 语言 | **TypeScript** |
| 样式 | **dart-sass / SCSS**（禁用 node-sass） |
| API | **NestJS + Prisma + PostgreSQL** |
| 管理后台 | **Vue3 + Vite** |
| 共享包 | **`packages/shared`** |
| 主目标端 | **微信小程序** |
| 扩展目标端 | **抖音小程序**、**小红书小程序** |
| 首期支付 | **不做**（预留费用字段） |
| 暂不纳入 | App、uni-app x、Vue2、微信云开发主后端 |

**一句话：** monorepo 内用 uni-app 做多端小程序，Nest 做权威业务与权限，Admin 做运营；用 ADR + roadmap 驱动开发。

## 2. 目录与包名

| 路径 | 包名 | 职责 |
| --- | --- | --- |
| `apps/mp` | `@activity/mp` | 用户端 + 组织者端小程序 |
| `apps/api` | `@activity/api` | HTTP API、鉴权、领域规则 |
| `apps/admin` | `@activity/admin` | 运营后台 |
| `packages/shared` | `@activity/shared` | 枚举、共享类型、契约常量 |

根脚本通过 `pnpm --filter` 调用各包，见根 `package.json`。

---

## 3. 为什么不用 uni-app x / 云开发主后端

- uni-app x 小程序端尚未覆盖抖音、小红书（截至文档基线）。  
- 微信云开发会锁死微信，与多端目标冲突。  
- 传统 uni-app 官方标识覆盖 `mp-weixin` / `mp-toutiao` / `mp-xhs`。

## 5. 工程约定

### 5.1 安装与脚本

```bash
pnpm install
pnpm dev:mp-weixin
pnpm dev:api
pnpm dev:admin
```

小程序产物：`apps/mp/dist/dev/<platform>` 或 `apps/mp/dist/build/<platform>`。

### 5.2 环境变量

- 小程序 / Admin（Vite）：`VITE_` 前缀（如 `VITE_API_BASE`）。  
- API：`DATABASE_URL`、JWT/会话密钥等，仅服务端；禁止提交真实密钥。  
- 禁止沿用 Vue2 的 `VUE_APP_*`。

### 5.3 多端分层（mp）

```text
共用层：页面、业务组件、请求封装、Pinia、shared 类型
分端层：登录、支付（未来）、分享、订阅消息 → adapters/
```

条件编译优先收口到适配模块。

### 5.4 API 原则

- 名额、报名状态、权限以服务端为准。  
- 报名接口需幂等；并发占用名额需事务或等效机制（ADR-0007）。  
- OpenAPI 由 Nest 导出，前端生成或手写客户端时对齐 `shared`。

### 5.5 UI 与依赖

- mp：优先 uni-ui 或明确支持 Vue3 的小程序组件库。  
- 禁止默认引入仅 Vue2 的旧库。  
- npm 包须可在小程序运行；依赖 `window`/`document` 的库默认不可用。

## 6. AI 文档驱动约定

1. 先读本文、`docs/roadmap.md`、`docs/product/prd-summary.md`、相关 ADR。

5. 详细流程见 [ADR-0002](./adr/0002-doc-driven-ai-workflow.md)。
