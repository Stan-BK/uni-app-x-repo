# 首页活动列表横卡改版设计规格

- **日期：** 2026-11-23  
- **状态：** Implemented（含 2026-11-27 右侧高度修订）  
- **范围：** 仅 `apps/mp` 首页发现列表；不改 API / Admin / 其他列表页  
- **参考：** 产品提供的活动列表横卡视觉（左缩略图 + 右文案 + 底栏标签）

## 1. 目标

将首页活动列表从「双列瀑布流竖卡」改为「单列横卡」，对齐参考图的阅读路径与信息层级；业务数据、点击行为、标签色体系保持不变。

成功标准：首页列表为单列横卡；标题单行省略；时间/地点带图标；费用与状态标签沿用现有 `ed-tag-*`；有报名者头像时显示在状态标签左侧。

## 2. 已确认决策

| 项 | 结论 |
| --- | --- |
| 改动范围 | 仅首页发现列表；我的报名、组织者列表本次不改 |
| 列表布局 | 单列横卡（去掉 `masonry` 双列） |
| 实现方式 | 直接改 `home/index.vue`，不抽公共卡片组件 |
| 标题 | 单行不换行，超长省略号 |
| 状态文案 | 继续用现有 `displayStatus`（报名中 / 已满员 / 已结束 / 报名截止） |
| 标签颜色 | 沿用现有：费用 `ed-tag-open` / `ed-tag-paid`；状态 `ed-tag-open` / `ed-tag-full` / `ed-tag-muted` |
| 报名者头像 | 有 `attendees` 才显示（最多 3），放在报名状态标签左侧；无则不占位 |
| 非目标 | 其他列表页、抽组件、改 API、改热门轮播 / 搜索 / 排序 / FAB |

## 3. 卡片结构

```
┌─────────────────────────────────────────┐
│ [封面缩略图]  标题（单行省略）            │
│               ⏱ 时间                    │
│               📍 地点（单行省略）          │
│               [费用]    [头像…][状态]     │
└─────────────────────────────────────────┘
```

- 左：正方形封面（圆角）；无 `coverUrl` 时品牌色占位  
- 右上→下：标题 → 时间行 → 地点行 → 底栏  
- 底栏：左费用标签；右为「可选头像叠层 + 状态标签」  
- 整卡点击 → 活动详情（行为不变）

## 4. 字段映射

| UI | 数据 / 逻辑 |
| --- | --- |
| 封面 | `item.coverUrl`；缺失用占位 |
| 标题 | `item.title`；`white-space: nowrap` + ellipsis |
| 时间 | `EdIcon` `clock` + `startAt` 本地短格式（如 `11月16日 (周日) 10:00`）；无效则「时间待定」 |
| 地点 | `EdIcon` `pin` + `item.place`；空为「—」；单行省略 |
| 费用 | 现有 `isFree` / `feeLabel`（免费 / `¥xx.xx`） |
| 状态 | 现有 `displayLabel` + `statusTag` |
| 头像 | 现有 `cardFaces`（`attendees` 最多 3）；仅 `length > 0` 时渲染 |

图标复用 `components/ed-icon/ed-icon.vue`（已有 `clock` / `pin`）。

## 5. 实现落点

| 路径 | 作用 |
| --- | --- |
| `apps/mp/src/pages/home/index.vue` | 列表模板由 masonry 竖卡改为单列横卡；调整样式；时间格式化贴近参考图；引入 `EdIcon` |

不新增组件文件；不改 `public-activities` API 契约。

## 6. 样式约束

- 卡片白底、大圆角、轻阴影，与现有 Urban Editorial token（`$ed-*`）一致  
- 横卡内边距与左右页边距沿用首页现有节奏，避免另起一套间距体系  
- 标签外形可继续用 `.ed-tag` 胶囊；**颜色 class 不新开**  
- 封面固定边长（正方形），不随标题高度被拉伸变形  
- **右侧内容总高应与封面底边视觉平齐**：不放大封面；通过收紧 `.body` 的 `gap`、标题/`meta` 行高、脚头多余 padding 实现（2026-11-27）
