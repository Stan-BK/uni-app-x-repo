# 活动列表横卡推广设计规格

- **日期：** 2026-11-28  
- **状态：** Implemented  
- **范围：** `apps/mp` — 抽公共横卡组件；首页迁入；「我的报名」「组织者活动列表」改为同系横卡（有操作时三列）  
- **前置：** [2026-11-23 首页活动列表横卡](./2026-11-23-home-activity-list-card-design.md)  
- **非目标：** 详情大封面、创建/编辑封面选择器、签到名册等非列表卡；API / Admin；新标签色体系

## 1. 目标

将仍为双列瀑布流竖卡的「我的报名」「组织者活动列表」对齐首页横卡阅读路径；通过单一组件避免三处 DOM/样式漂移。有页内操作时采用三列：封面 | 信息 | 操作。

成功标准：三页共用 `activity-list-card`；报名/组织者为单列三列式（无操作时可不渲染第三列）；首页为同组件两列；原操作语义与点击进详情行为不变。

## 2. 已确认决策

| 项 | 结论 |
| --- | --- |
| 改动页面 | 首页 + 我的报名 + 组织者活动列表 |
| 实现方式 | 抽公共组件 + `#actions` slot（方案 1） |
| 有操作时布局 | 三列：封面 \| 信息 \| 操作（竖排，最右列） |
| 无操作时 | 不渲染操作列（首页） |
| 操作策略 | 混合：主操作留在卡上；业务 `can*` 仍在各页 |
| 列表布局 | 去掉 masonry，改为单列 |
| 封面 | 固定 `168rpx` 方图；右侧信息区高度与封面底边平齐（沿用 11-27 收紧节奏） |

## 3. 组件结构

路径：`apps/mp/src/components/activity-list-card/activity-list-card.vue`

```
┌────────┬─────────────────────────┬──────────┐
│ 封面   │ 标题（单行省略）         │ #actions │
│ 168²   │ ⏱ 时间 / 📍 地点        │ 竖排按钮 │
│        │ 脚头标签 / 头像…         │（可选）  │
└────────┴─────────────────────────┴──────────┘
```

### 3.1 Props / 插槽（约定）

| 输入 | 说明 |
| --- | --- |
| `coverUrl` | 已解析的封面 URL；空则品牌占位 |
| `title` | 标题 |
| `timeText` | 已格式化的时间文案 |
| `place` | 地点；空展示「—」 |
| `#foot` | 脚头（费用/状态/头像等）全部由调用方组合，组件不内置三页业务枚举 |
| `#actions` | 有 slot 内容才渲染第三列；按钮须 `@click.stop` |

整卡可 `@click` 进详情（由页面监听）；操作列内点击不冒泡。

### 3.2 字段映射

| 区域 | 首页 | 我的报名 | 组织者列表 |
| --- | --- | --- | --- |
| 封面 | `coverUrl` | `activity.coverUrl` | `coverUrl` |
| 标题 | `title` | `activity.title` | `title` |
| 时间/地点 | `startAt` / `place` | 来自 `activity` | `startAt` / `place` |
| 脚头 | 费用 + 头像 + `displayStatus` | 报名 `status` 标签 | 生命周期标签 |
| 操作列 | 无 | 去支付 / 签到码 / 取消 | 发布 / 退回草稿 / 取消 / 编辑 |

时间短格式与首页横卡对齐。封面 `@error` 占位可在组件内处理，或由页传入已清空的 `coverUrl`。

## 4. 样式约束

- `$ed-*` token；标签继续 `ed-tag-*`，不新开色系  
- 中栏 gap / 行高与 11-27 首页修订一致，与 `168rpx` 封面底边视觉平齐  
- 操作列窄、竖排；主操作 `ed-btn`，次要 `ed-btn-link` / `ed-btn-secondary` / 危险样式沿用现页  
- 三列之间 gap 与现横卡内边距节奏一致  

## 5. 实现落点

| 路径 | 作用 |
| --- | --- |
| `components/activity-list-card/activity-list-card.vue` | 新建公共横卡 |

| `pages/mine/registrations.vue` | 单列 + 组件 + `#actions` |
| `pages/organizer/list.vue` | 单列 + 组件 + `#actions` |

不改 API 契约。
