# Superpowers 产物目录

本目录存放 [Superpowers](https://github.com/obra/superpowers) 工作流产出的设计与实现计划，与 ADR / roadmap 互补：

| 类型 | 路径 | 说明 |
|------|------|------|
| 设计（spec） | `specs/YYYY-MM-DD-<topic>-design.md` | brainstorming 批准后落盘 |
| 计划（plan） | `plans/YYYY-MM-DD-<feature-name>.md` | writing-plans 产出，供按任务执行 |

## Cursor

- 用户级：安装 marketplace 插件 `superpowers`
- 仓库级：见 `.cursor/rules/superpowers-workflow.mdc`

跨模块决策、支付/权限等仍以 `docs/adr/` 为准；本目录不替代 ADR。
