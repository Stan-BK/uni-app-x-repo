# 后端选型与阶段升级路线

> **状态：** Confirmed（产品方确认 2026-10-18）  
> **关联 ADR：** [0010](./adr/0010-backend-ops-stack.md)  
> **用途：** 按项目阶段做服务开发与基础设施升级时的唯一选型基线。变更先改本文与 ADR-0010，再改代码/云资源。

**未勾选但阶段交付仍要求的底座（来自节奏 14A）：**

| 能力 | 何时做 | 说明 |
| --- | --- | --- |
| 可观测与告警 | 地基最小集 → 稳定化补齐 | 日志、错误率、延迟告警 |

## 3. 四阶段升级（开发时按此开闸）

### 阶段 A — 地基（当前 → P0-1 收尾 / P0-6 前）

**目标：** 能安全调开放平台、能联调、能部署体验环境。

| 项 | 标准 |
| --- | --- |
| 计算 | NestJS 单体；本地 / 单机 Docker + Nginx |
| 数据 | 阿里云或自建 PostgreSQL **单主**；日备开启 |
| 会话 | JWT / DB，无 Redis |
| 域名 | HTTPS 合法域名（微信 request / upload） |
| 平台 | **仅微信**登录闭环 |
| 观测 | 结构化日志 + 基础存活探针 |
| 密钥 | 仅服务端环境变量；禁止进小程序 |

**不做：** Redis、MQ、K8s、抖音/小红书登录、支付。

### 阶段 B — 业务闭环（P0-2～P0-6）

**目标：** 活动发布—发现—免费报名—组织者名单—后台审核可试运营。

| 项 | 标准 |
| --- | --- |
| API | 活动 / 报名 / 审核领域接口完备 |
| 存储 | **阿里云 OSS**；公开读资源走 **CDN** |
| 配置 | 运营开关 / 强制更新提示（可先简单表或配置接口） |
| 异步 | 进程内（如发订阅消息重试可先同步+有限重试） |
| 平台 | 仍以微信为主；抖音/小红书接口保持预留 |
| 观测 | 错误追踪（如 Sentry 类）+ 关键接口延迟 |

**已进仓库：** `deploy/docker-compose.yml`（API + Postgres + Nginx 单机）；手册 `docs/deploy-docker.md`。HTTPS、OSS/CDN、Sentry、配置下发仍后置。

**不做：** 在线收款、主从强制、容器多副本（可预研）。

### 阶段 C — 有交易再上（产品 P2，独立里程碑）

**前置：** P0 免费闭环验收通过；支付相关 ADR `Accepted`。

| 项 | 标准 |
| --- | --- |
| 领域 | 订单状态机、下单、支付回调验签、退款、对账、幂等 |
| 平台 | 优先微信支付；其他端按开通情况适配 |
| 异步 | 对账 / 消息补发：**评估引入云 MQ + Worker**（突破 8A） |
| 缓存 | 热点与回调去重：**评估引入 Redis**（突破 6A） |
| 触达 | 订阅消息（报名成功 / 支付结果 / 活动提醒） |

### 阶段 D — 稳定化（增长 → 稳定运营）

**目标：** 活动峰值与支付峰值可预期；故障可回滚。

| 项 | 标准 |
| --- | --- |
| 计算 | **容器服务 ≥2 副本跨 AZ**（替代单机 Docker） |
| 数据 | PostgreSQL **主从 + PITR**；演练恢复 |
| 网关 | 限流、鉴权、版本化 |
| 队列 / 缓存 | 按阶段 C 评估结果固化 Redis / MQ |
| 密钥 | KMS / 密钥管理；轮换流程 |
| 平台 | 按需开通抖音、小红书登录与能力 |
| SLO | 可用性 ≥99.9%；核心接口 P95 &lt;300ms（同城）；支付可对账 100% |

## 4. 与 `docs/roadmap.md` 的映射

```text
P0-0 工程基座          → 阶段 A（部分完成）
P0-1 身份与权限        → 阶段 A（进行中/已勾选）
P0-2～P0-5 活动/报名/审核 → 阶段 B
P0-6 端到端验收        → 阶段 B 出口
P1 订阅消息等          → 阶段 B 尾声或阶段 C 前
P2 微信支付/订单       → 阶段 C
运维升级（副本/主从等） → 阶段 D（可与 C 并行启动）
```

功能开发跟 `roadmap.md` 的 P0/P1/P2；**云资源与中间件升级跟本文阶段 A–D**。两者同时满足才算该阶段完成。

---

## 5. 推荐默认拓扑（MVP）

```text
微信小程序 (apps/mp)
    → HTTPS → Nginx
        → NestJS (apps/api)  ×1  Docker
            → PostgreSQL 单主
            → 阿里云 OSS（阶段 B）
            → 微信开放平台（登录；支付在阶段 C）

Vue Admin (apps/admin) → 同一 API
```

稳定化后在此拓扑上增加：第二副本、RDS 只读、Redis、MQ Worker、CDN、KMS。

---

## 6. 变更规则

1. 改云厂商 / 数据库引擎 / 是否首期支付：先改 ADR-0010 与本文，再改实现。  
2. 从阶段 A/B 提前引入 Redis/MQ/多副本：需在 PR/ADR 写明触发条件（QPS、故障或支付上线）。  
3. AI 与人工开发：**当前阶段未开放的能力不得实现为可收款/可对公资金路径**。
