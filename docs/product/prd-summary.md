# 产品需求摘要（来自 PRD V1.0）

原文：`docs/产品文档.docx`（活动报名类微信小程序 PRD 模板）。  
**修订：** 2026-10-19 起活动发布规则以 [ADR-0005](../adr/0005-activity-lifecycle-and-model.md) 为准（不再要求活动必审）。

## 一句话定位

面向公众的活动发现与报名小程序：组织者发布活动，用户浏览并报名，平台后台治理与下架。

## 角色

| 角色 | 核心能力 |
| --- | --- |
| 访客/用户 | 浏览、报名、我的报名 |
| 组织者 | 创建/管理活动、查看报名名单 |
| 平台运营/管理员 | 组织者权限、活动下架、基础 RBAC |

## 首期必须交付（P0）

- 活动创建/编辑/草稿/直接发布（无活动审核队列）  
- 活动列表与详情  
- **免费**报名闭环（幂等、名额、防重复）  
- 我的报名 + 组织者报名名单  
- 后台组织者治理 / 活动下架 + 基础权限  

## 首期不做

在线支付/退款/分账打款、扫码签到、评价、候补、优惠券/分销、复杂推荐、多场次系列活动。

**后置（已确认进路线图）：** 收费活动报名 / 微信支付（平台代收）→ 活动结束后抽成结算给组织者 → 产品 P2，基础设施见 `docs/backend-ops-roadmap.md` 阶段 C。活动表可预留 `feeType`/`feeCents`/`platformFeeBps` 等字段。

## 已锁定的产品默认

见设计规格与 ADR-0001 / ADR-0005 关联结论；明细表：

| ID | 默认 |
| --- | --- |
| D-01 | 申请成为组织者后可发布 |
| D-02 | 组织者可直接发布活动；运营可下架（`removed`）；无活动审核队列（修订自「新组织者活动必审」） |
| D-03 | 报名默认直接成功（免费活动） |
| D-04 | 名额按有效报名记录数 |
| D-05 | 首期不开放在线收款；可创建付费活动字段，支付链路后置 |
| D-06 | 用户可主动取消本人报名（P0-4，活动未结束前）；组织者退回草稿/取消/运营下架时系统取消有效报名（退费随支付） |
| D-07 | 独立 Web 管理后台 |
| D-08 | 表单：姓名 + 手机号 |
| D-09 | 线上活动首期可不做；地点按线下字段 |
| D-10 | 联系方式避免裸露隐私 |

## 核心状态（逻辑）

- 活动生命周期：`draft | published | cancelled | removed | ended`（单一状态；`ended` 可由时间计算）  
- 组织者发布选项：退回草稿或取消活动；运营下架为 `removed`  
- ~~活动审核态~~：已废弃（见 ADR-0005）  
- 报名：`confirmed`（首期免费）；`pending_review` 等预留；支付态随支付 ADR  

## 关键非功能

- 服务端判定名额与权限，不信任前端  
- 报名接口幂等；并发不超卖  
- 敏感操作审计（含运营下架）  

## 验收锚点

PRD 第十章：`AT-ACT-*`、`AT-REG-*`、`AT-ADM-*`，**以 Accepted ADR 修订为准**。  
活动发布：AT-ACT-01～03 + ADR-0005 修订路径；原 AT-ACT-04/05（提交审核/驳回）不再作为 P0 验收。
